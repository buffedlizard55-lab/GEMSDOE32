3. Which instrument to trust (measured)

  • Spearman rank correlation of SGMC-cal with owner-reported live scores across 11 restored files: 0.90.
  • Spearman of the static hide-and-recover diagnostic with live scores: 0.05. It does not track live rank and must not be used to pick a file.
  • Fold-local HR values on the candidate cards come from the per-fold pipeline. The shipped files do not reproduce them on the static path, so each needs its own per-fold receipt before a claim is promoted.
  • Contamination: hsupsgmc used SGMC north pixels as training positives, and the bayesopt file was selected using SGMC-cal in its objective (IR-20261028-04). Their SGMC values are not independent evidence.

4. What blocks a submission (owner decisions, not automatic)

  1. Lattice rule. Only 0 of 51 competitive rasters pass the 70% rule against the 13gems lattice. The owner must either (a) record a written exemption for dense calibration rasters, or (b) accept that no competitive-size file can be submitted under the literal rule.
  2. Per-candidate fold-local receipts. Each HR claim needs its own per-fold re-emission receipt.
  3. Selection bias. SGMC-cal has been used as a selection criterion. A held-out instrument is needed for future selection.
  4. Slot selection. Promotion to a live slot is a separate selector step. Nothing here authorizes a weekly slot.

Non-lattice gate: 16 of 51 competitive rasters pass the 70% rule against other on-disk rasters (the receipt's 17 of 52 counts the lattice itself, which trivially passes). This is not a submission pass, because the lattice rule still applies.
